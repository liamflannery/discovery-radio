Discovery Radio

Pick a song or artist. Get a playlist that wanders off from it.

Add this to your Home Screen first

Tap Share ⬆︎ then Add to Home Screen, and open Discovery Radio from its icon. Do the setup there: on iPhone, the Home Screen app keeps its own storage, separate from Safari.

Welcome! Let's get you set up.

Three steps, about 5 minutes, done once. You'll need Spotify Premium (Spotify requires it for developer apps) and a free Last.fm account. Your keys and login are stored only on this device.

Already set up on a computer? Paste a setup code

You still need to add this page's Redirect URI (step 1) to your Spotify app.
